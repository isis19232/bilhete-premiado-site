# Publicar no Netlify

## Upload manual (Netlify Drop)

1. Extraia o arquivo ZIP.
2. Acesse https://app.netlify.com/drop e entre na sua conta.
3. Envie a pasta `public`, que contém `index.html`, CSS e imagens.
4. Aguarde o Netlify informar o endereço publicado.

Para atualizar um projeto existente, abra a aba Deploys desse projeto e envie a pasta public na área de deploy manual.

## Integração com GitHub

Envie todo o conteúdo deste projeto para o repositório desejado, mantendo netlify.toml na raiz e os arquivos do site dentro de public. Importe o repositório no Netlify: branch main, diretório base vazio, comando de build vazio, diretório de publicação public.

## Prompt

O arquivo PROMPT-NETLIFY.txt contém instruções prontas para copiar em um assistente de publicação. O prompt sozinho não envia arquivos: o assistente precisa ter acesso ao projeto e à conta do Netlify.
